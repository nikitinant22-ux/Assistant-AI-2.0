# Assistant AI 3.0

Десктопный ассистент для инженерной работы с AutoCAD: интерфейс Fluent Design
на PyQt6 и маршрутизатор запросов к локальным языковым моделям через Ollama.

## Текущее состояние

Идёт переход с версии 2.0 на 3.0. Готов интерфейс и слой маршрутизации; база
атомарных операций pyautocad пока пуста, поэтому маршрутизатор работает в
режиме интеллектуальной заглушки и подготовлен под Function Calling.

Практически это значит: ассистент понимает запрос, определяет намерение и
отвечает — но чертёж пока не строит. Код версии 2.0, включая слой работы с
AutoCAD через COM, лежит в папке `Archive/` и вытаскивается оттуда по частям.
После завершения переноса папка будет удалена.

## Устройство

| Модуль | Роль |
|---|---|
| `cad_ui_core.py` | окно приложения, Fluent Design на `QMainWindow`. Точка входа |
| `cad_ui_styles.py` | оформление интерфейса |
| `main_router.py` | разбор намерения и выбор маршрута исполнения |
| `core_core.py` | работа с Ollama: `OllamaWorker`, `ChainedChatWorker` |
| `cad_reference.md` | справочник по API, из него берётся контекст для ответов |
| `icons/` | иконки интерфейса в SVG |
| `Archive/` | код версии 2.0, временно, до завершения переноса |

Маршрутизатор различает три режима — диалог, помощник и песочница. В режиме
помощника запрос с глаголом действия («начерти», «построй», «вставь») уходит
к `mistral-small:22b`, которая читает справочник и отвечает по существу
операции. Прочие запросы идут в диалог с `deepseek-r1:14b`.

Маршрутизатор не исполняет код: `exec()` и `eval()` не применяются, он
возвращает решение словарём, а исполнением занимаются статичные классы.

## Требования

- Windows с установленным AutoCAD — понадобится, когда заработает слой
  построения; интерфейс и диалог с моделями работают и без него
- Python 3.11
- [Ollama](https://ollama.com), запущенная локально на `http://localhost:11434`

Модели нужно скачать заранее:

```
ollama pull deepseek-r1:14b
ollama pull mistral-small:22b
```

## Установка и запуск

```
pip install PyQt6 PyQt6-Fluent-Widgets requests
python cad_ui_core.py
```

Тот же список объявлен в `pyproject.toml`. Ставится он здесь вручную, а не
через `pip install -e .`: в корне лежат несколько самостоятельных модулей,
и автоматическое определение состава пакета на такой раскладке не работает
без отдельной настройки сборки.

Ставить одновременно несколько вариантов Fluent Widgets — `PyQt-`, `PyQt6-`,
`PySide2-`, `PySide6-` — нельзя: у всех четырёх один и тот же импорт
`qfluentwidgets`.

## Локальные файлы

`settings.json` и `chat_history.json` создаются при первом запуске, хранят
настройки и историю конкретного пользователя и в репозиторий не попадают.
