"""Модуль дизайн-кода интерфейса «Бесшовного пространства» (Канон 16.5).

Данный модуль является единственным источником правды для всей визуальной
стилистики парящего безрамочного интерфейса Fluent Design на PyQt6 +
qfluentwidgets. Он содержит:

    * Палитру цветов Windows 11 (сплошной графит, микро-контрасты хаба);
    * Единую глобальную таблицу стилей QSS для всех виджетов;
    * Вспомогательные функции построения градиентов угасания (Fade-out).

По правилу Канона 4.2 иерархия строится так: графическая оболочка UI общается
с логикой исключительно через чистые данные (JSON/словари), а вся стилистика
вынесена в отдельный, стерильный слой. Здесь нет никакой бизнес-логики —
только «пока-ёкэ» визуального каркаса.

Внутренние идентификаторы, ключи и пути пишутся на английском ASCII, а весь
человекочитаемый текст (docstrings, комментарии) — строго на русском языке.

# =============================================================================
# ГРАДИЕНТЫ УГАСАНИЯ (FADE-OUT) — «Пока-ёкэ» от ослепшего зрения
# =============================================================================
def paint_fade_out(widget: QWidget, painter: QPainter, height: int) -> None:
    """Рисует мягкий линейный градиент угасания снизу вверх.

    Накладывается над нижней частью чат-зоны, непосредственно над парящей
    капсулой ввода. Сверху (высота = height) градиент абсолютно прозрачен,
    а снизу достигает 100% плотности цвета фона окна (#1e1e1e). За счёт этого
    текст чата при прокрутке красиво «растворяется», уходя за парящее поле.

    Args:
        widget: виджет-оверлей, на котором выполняется отрисовка.
        painter: активный объект QPainter виджета.
        height: физическая высота градиентного слоя в пикселях (обычно 40px).
    """
    rect = widget.rect()
    gradient = QLinearGradient(0, 0, 0, height)
    # Верхний край слоя — полностью прозрачный.
    gradient.setColorAt(0.0, QColor(Palette.GRAPHITE + "00"))
    # Нижний край — 100% плотный графит фона окна.
    gradient.setColorAt(1.0, QColor(Palette.GRAPHITE))
    painter.fillRect(rect, gradient)


def paint_hub_fade_line(widget: QWidget, painter: QPainter) -> None:
    """Рисует горизонтальную черту, плавно угасающую по краям (Fade-out Line).

    Располагается в «Инженерном хабе» под неподвижными кнопками управления.
    Центр черты плотный (цвет разделителя), а левый и правый края плавно
    растворяются в прозрачность — без жёстких линий и перегородок.

    Args:
        widget: виджет, на котором рисуется черта (используется его ширина).
        painter: активный объект QPainter виджета.
    """
    w = max(1, widget.width())
    y = widget.height() // 2
    # Горизонтальный градиент: прозрачный слева -> плотный в центре -> справа.
    gradient = QLinearGradient(0, 0, w, 0)
    gradient.setColorAt(0.0, QColor(Palette.DIVIDER + "00"))
    gradient.setColorAt(0.5, QColor(Palette.DIVIDER))
    gradient.setColorAt(1.0, QColor(Palette.DIVIDER + "00"))
    painter.fillRect(0, y - 1, w, 2, gradient)
